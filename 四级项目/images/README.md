# Days Matter倒数日网页复刻项目
作者：邢菲洋
学号：24002120117
课程：高级网页设计I

## 项目介绍
本项目复刻移动端倒数日APP的3个页面：首页、侧边栏菜单、添加新日子页面。移动端适配，浏览器开发者工具切换移动端模式可还原布局。
## 技术架构
HTML5 + CSS3原生布局 + JavaScript（内嵌页面）
图标来源：iconfont阿里巴巴矢量图标库
## 文件目录说明
- index.html：项目首页
- menu.html：侧边栏菜单页面
- add.html：添加新日子页面
- css/xfy_global.css 全局样式表
- images文件夹：存放本地图片资源
- svg.css:图标样式
## 运行指南
1. 全部文件解压放在同一个文件夹
2. 使用VSCode打开文件夹，使用Live Server插件打开index.html
3. 浏览器F12打开开发者工具，切换手机设备模拟移动端查看效果
4. 点击左上角三横线打开菜单页面，再点左上返回；点击右上角加号打开添加页面，点左上返回。
