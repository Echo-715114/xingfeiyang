# 抓小球小游戏 — 需求规格说明书（spec.md）

- 版本：v1.0
- 日期：2026-10-21
- 技术栈：原生 HTML5 + CSS3 + JavaScript（ES6+）
- 交付形态：可直接双击 `index.html` 在浏览器运行的静态网页

---

## 1. 项目概述

一款限时点击类休闲小游戏。玩家在 2 分钟内尽可能多地点击随机出现的蓝色小球：命中 +2 分，点击空白 -1 分，时间结束后结算本局得分与历史最高分。

### 1.1 目标

- 规则简单、上手即玩，单局时长固定 2 分钟。
- 纯前端实现，无构建工具、无第三方库、无外部素材。
- 桌面鼠标与移动端触屏均可流畅游玩。

### 1.2 非目标（YAGNI，本期不做）

- 排行榜、账号体系、后端存储。
- 多球同屏、小球移动、难度递增、道具、连击。
- 音效与背景音乐。
- 暂停 / 继续、关卡选择。
- 键盘操作、无障碍读屏的完整适配。
- 暗色模式。

## 3. 页面结构与视觉规范

### 3.1 页面分区

```
┌─────────────────────────────────────┐
│ 顶部栏：标题「抓小球」  分数  倒计时  │  ← 固定高度，不参与点击判定
├─────────────────────────────────────┤
│                                     │
│           游戏区（浅黄色背景）        │  ← 小球随机出现在此区域
│                                     │
├─────────────────────────────────────┤
│ 底部提示：点中小球 +2，点空 -1        │  ← 不参与点击判定
└─────────────────────────────────────┘
```

- 顶部栏：左侧标题，中间实时分数，右侧倒计时（`mm:ss`）。三项始终可见。
- 游戏区：占满剩余高度，是所有小球定位与点击判定的唯一区域。
- 底部提示：静态文案，不响应点击计分。
- 三个区域之外（body、顶部栏、底部提示）的点击一律不计分。

### 3.2 视觉规范

| 元素 | 规范 |
| --- | --- |
| 页面背景 | 浅黄色 `#FFF8DC`（cornsilk） |
| 顶部栏 | 半透明白色卡片（`rgba(255,255,255,.72)`），底部 1px 暖色分隔线 |
| 主文字 | 深灰棕 `#3B3A32`，系统字体栈（含中文黑体回退） |
| 分数 | 28–36px 加粗，游戏进行中数值变化时有 150ms 缩放强调 |
| 倒计时 | 22–26px 等宽数字（`font-variant-numeric: tabular-nums`），低于 10 秒变橙红色 `#E4572E` |
| 小球 | 直径 60px（移动端 52px），正圆，蓝色径向渐变 `#4FA8FF → #1E6FD9`，白色高光与柔和投影 |
| 小球交互 | `cursor: pointer`，悬停轻微放大（桌面端），按下轻微缩小 |
| 按钮 | 蓝色实心圆角按钮，白字，悬停加深，按下回弹 |
| 结算面板 | 居中卡片，白色背景、大圆角、阴影，背景半透明遮罩 |

### 3.3 层次与动效

- 遮罩层（开始页 / 预备倒计时 / 结算面板）覆盖游戏区，`z-index` 高于小球。
- 所有动画时长 150–300ms，使用 `transform` + `opacity`，避免触发布局抖动。
- 小球出现：150ms 内由 0.6 倍缩放 + 透明淡入至正常大小。

## 4. 游戏流程与状态机

### 4.1 状态定义

| 状态 | 说明 | 分数可变化 | 小球可见 |
| --- | --- | --- | --- |
| `idle` 待开始 | 显示开始页，等待点击「开始游戏」 | 否 | 否 |
| `countdown` 预备倒计时 | 显示 3 → 2 → 1，每秒切换 | 否 | 否 |
| `playing` 进行中 | 正式 2 分钟计时，可点击计分 | 是 | 是 |
| `ended` 已结束 | 时间到，显示结算面板 | 否 | 否 |

### 4.2 流程

1. 打开页面 → `idle`：游戏区显示开始页（规则说明 + 「开始游戏」按钮），分数 `0`，倒计时 `02:00`。
2. 点击「开始游戏」→ `countdown`：遮罩依次显示 `3`、`2`、`1`，每个数字 1 秒（带缩放淡入淡出）。
3. 倒计时结束 → `playing`：遮罩消失，倒计时立即从 `02:00` 开始每秒递减，同时在游戏区随机位置生成第一个小球。
4. 玩家点击小球或空白区域，实时更新分数与反馈（见第 5 节）。
5. 倒计时归零 → `ended`：立即停止计时与所有点击计分，小球消失，弹出结算面板，展示本局得分、历史最高分、是否破纪录，以及「再来一局」按钮。
6. 点击「再来一局」→ 分数归零、倒计时重置为 `02:00` → 回到步骤 2（重新 3 秒预备倒计时）。

### 4.3 计时规则

- 正式计时总长 120 秒，使用 1 个 `setInterval`（1000ms）递减剩余秒数。
- 显示格式 `mm:ss`，初始 `02:00`，每秒更新一次，归零后显示 `00:00`。
- 剩余时间 ≤ 10 秒时数字变橙红色。
- 时间到必须清除计时器，避免重复结算或幽灵计分。
- 页面刷新即重置本局，最高分保留。

## 5. 功能需求

### FR-1 开始与倒计时

- 开始页包含：游戏名、一句话规则（2 分钟，点球 +2，点空 -1）、「开始游戏」按钮。
- 点击按钮后按钮不可再次触发；3 秒预备倒计时结束后才进入正式计时。
- 预备倒计时期间点击页面任何位置均不计分。

### FR-2 小球生成

- 场上任意时刻最多 1 个可点击小球。
- 小球以绝对定位放置于游戏区内，随机位置须完整落在游戏区内，四周保留至少 12px 安全边距。
- 新位置与上一个位置的中心距离尽量不小于球半径的 1.5 倍（最多重试 10 次，仍不满足则采用最后一次结果），避免"原地刷新"观感。
- 小球生成后带 150ms 淡入缩放动画。

### FR-3 命中小球

- 点击小球本体：分数 `+2`。
- 命中时小球立即禁用点击（防止连点重复计分），播放 150ms 缩小淡出动画后移除。
- 动画结束后在随机新位置生成下一个小球。
- 命中不计为空白点击，不会再触发 -1。

### FR-4 点击空白

- 在游戏区内、但未点中小球本体时：分数 `-1`。
- 点击后小球位置保持不变，继续可点。
- 分数允许为负数。
- 点击顶部栏、底部提示、遮罩层、按钮、结算面板均不计分。
- 快速连续点击空白，每次点击都独立扣 1 分。

### FR-5 分数展示

- 顶部栏实时展示当前分数，正负号均正常显示（如 `-3`、`0`、`14`）。
- 分数变化时数字有 150ms 缩放强调动画。
- 分数不设上下限。

### FR-6 时间结束与结算

- 时间归零立即结算，停止计时器，禁用小球与游戏区计分。
- 结算面板展示：
  - 本局得分（大字）
  - 历史最高分（来自 localStorage，无记录时显示 `0`）
  - 破纪录提示：本局得分 > 原最高分时显示「新纪录！」
  - 「再来一局」按钮
- 本局得分 > 原最高分时，将最高分更新并持久化；得分相等不算破纪录。
- localStorage 不可用或数据非法时，按无记录处理（最高分 0），不得抛错阻断游戏。

### FR-7 再来一局

- 重置分数为 0、剩余时间为 120 秒，清除残留动画与飘字，隐藏结算面板。
- 重新执行 3 秒预备倒计时后开始新一局。
- 最高分记录不重置。

## 6. 交互反馈

| 事件 | 视觉反馈 | 时长 |
| --- | --- | --- |
| 命中 | 点击位置飘出绿色 `+2`，向上移动并淡出；小球缩小淡出 | 600ms / 150ms |
| 点空 | 点击位置飘出红色 `-1`，向上移动并淡出；游戏区轻微左右抖动 | 600ms / 200ms |
| 分数变化 | 顶部分数数字缩放强调 | 150ms |
| 控场倒计时 | 数字 3、2、1 依次放大淡入再淡出 | 每个 1s |
| 低时间提醒 | 剩余 ≤10s 时倒计时变橙红 | 持续 |
| 小球生成 | 0.6 倍缩放 + 透明 → 正常 | 150ms |

- 飘字定位以点击坐标为准，限制在游戏区可视范围内，不溢出。
- 不加入任何音效。
- 飘字动画结束后从 DOM 移除，避免节点堆积。

## 7. 点击判定与事件处理约定

- 小球元素与游戏区均监听 `click`；小球回调中调用 `stopPropagation()`，确保一次点击只结算一次。
- 统一使用 `click`，不同时绑定 `touchstart`，避免移动端重复触发。
- 游戏区使用 `touch-action: manipulation`，减少移动端 300ms 点击延迟并禁止双击缩放。
- 只有状态为 `playing` 且事件发生在游戏区内部时才计分。
- 小球淡出动画期间设置 `pointer-events: none`，防止重复命中。
- 页面文字设置 `user-select: none`，防止连点选中文字。

## 8. 响应式与适配

- `viewport` 设置为 `width=device-width, initial-scale=1`。
- 页面采用 `flex` 纵向布局：顶部栏固定高度、游戏区 `flex: 1`、底部提示固定高度；整体不出现滚动条。
- 游戏区尺寸随窗口变化实时可用，小球位置始终基于当前游戏区尺寸计算；窗口缩放后，当前小球若越界则重新放置到合法位置。
- 移动端（宽度 ≤ 480px）：小球直径 52px，顶部分数 24px，倒计时 18px，保留足够指触面积。
- 桌面端与移动端共用同一套逻辑，不做两套代码。

## 9. 关键实现要点（供后续任务拆解参考）

- 单一状态对象管理：`{ phase, score, timeLeft, bestScore, timerId, countdownId }`，所有 UI 更新由状态驱动。
- 三个独立计时器需可被安全清理：预备倒计时、正式倒计时、单个飘字动画（飘字以 CSS 动画 + `animationend` 移除）。
- 随机坐标计算函数：输入游戏区宽高与球直径，输出合法左上角坐标。
- 最高分读写封装为小函数，内部 `try/catch` 处理隐私模式或异常数据。
- 不引入 `requestAnimationFrame` 游戏循环，小球为静态元素，减少复杂度。

## 10. 验收标准（人工测试清单）

1. 打开页面：浅黄色背景，顶部显示分数 `0`、倒计时 `02:00`，游戏区显示开始页。
2. 点击「开始游戏」：出现 3 → 2 → 1 预备倒计时，期间点击页面不加减分。
3. 倒计时结束：遮罩消失，正式计时从 `02:00` 开始递减，游戏区出现 1 个蓝色圆形小球。
4. 点击小球：分数 +2，出现绿色 `+2` 飘字，小球消失并在新随机位置出现。
5. 点击游戏区空白：分数 -1，出现红色 `-1` 飘字，页面轻微抖动，小球位置不变。
6. 连续点击空白至负分：分数正确显示负数，不报错、不卡死。
7. 点击顶部栏、底部提示、开始按钮区域：分数不变。
8. 小球动画期间快速连点同一位置：只结算一次，不重复加分。
9. 倒计时剩 10 秒内：数字变为橙红色。
10. 倒计时归零：立即停止计分，小球消失，弹出结算面板，显示本局得分与最高分。
11. 首次得分高于 0：显示「新纪录！」，刷新页面后最高分仍在。
12. 得分低于最高分：不显示「新纪录！」，最高分不变。
13. 点击「再来一局」：分数归零、时间回到 `02:00`、重新 3 秒倒计时、可正常开始新一局。
14. 拖动改变窗口大小（或手机横竖屏切换）：小球不越界，计分与计时正常。
15. 手机触屏点击小球/空白：只触发一次计分，无 300ms 明显延迟，无双击缩放。
16. 控制台无报错，刷新与重复开局无残留计时器导致的重复结算。
