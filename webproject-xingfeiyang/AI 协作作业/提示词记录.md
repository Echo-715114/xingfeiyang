## 任务一 · 提示词工程师：两轮迭代记录

**目标需求**：生成 `new Swiper('#wySw4', {...})` 配置——① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果为 cube。

### 第 2 轮（精确版——逐条拆解需求）

**我的提示词：**

> 生成 new Swiper('#wySw4', {...}) 配置：① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果为 cube。

**AI 回答（粘进页面验证用的完整代码）：**

```js

```

**验证**：先 `destroy(true, true)` 销毁页面原实例再按新配置重建（换配置必须销毁重建）。两轮代码先后粘入控制台并截图对比——第 1 轮缺 `effect` 是平推，第 2 轮出现 cube 立方体，四个需求逐条对应全部达标（截图见入口页「任务一」验证区）。

## 任务二 · creative 第 7 种效果（AI 读官网教我）

### 第 1 轮（先读懂官网 demo 257 的写法）

**我的提示词：**

> 用 creative（自定义变换），打开官方示例 swiper/demo/257-effect-creative.html，我会配合你读懂 creativeEffect 的 transform 写法，为演示四新增第 7 个按钮「creative 电影墙」。效果要求：上一张缩小左移并带角度、下一张放大右移进场（参数你问我然后我会回答你来实现定制，但要"像电影选片墙"）

**AI 回答：**

我读了官网 demo 257（effect-creative）的源码，先把 `creativeEffect` 的写法讲清楚，再向你确认 3 个参数：

**原理**：`effect: 'creative'` 时，Swiper 不再用内置效果，而是按你在 `creativeEffect.prev` / `creativeEffect.next` 里写的变换来摆"上一张"和"下一张"，切换时 Swiper 自动在两组变换之间做补间动画。

**transform 三件套**（demo 257 里每张 slide 都是这三项组合）：

| 项 | 写法 | 含义 |
|---|---|---|
| `translate` | `[x, y, z]` | 位移。**百分比相对 slide 自身的宽/高**（z 是像素） |
| `rotate` | `[x, y, z]` | 旋转。做平面选片墙只用第 3 个值（z 轴角度，正值顺时针） |
| `scale` | `0.8` 这类数字 | 缩放倍数，1 = 原尺寸 |

**另有一个 `limitProgress`**：默认 1 表示只对相邻 1 张应用变换，再远的 slide 藏起来——选片墙保持画面干净就靠它。

**在动手前，请你回答 3 个参数问题**（答完我给完整配置）：

1. 「上一张缩小」缩到多少倍？（demo 257 的地球效果用的是 0.9 左右，选片墙感更强的话建议 0.8）
2. 「左移」移多远？（slide 宽度的 100% 是正好出画，想留一点边就 110%~115%）
3. 角度方向：上一张往哪边歪、歪几度？（电影选片墙通常 ±5°~10°，别太大否则字看不清）

### 第 2 轮（我回答参数，AI 给完整配置）

**我的回答（提示词）：**

> 0.8，110%，歪 5°

**AI 回答：**

好，按你的参数来——上一张：缩小 0.8、左移 slide 宽度的 110%、逆时针歪 5°；下一张我做对称设计：右移 110% 进场、顺时针歪 5°、放大到 1.05 增强迎面感。完整配置如下（加进 `effect: 'creative'` 的实例）：

```js
creativeEffect: {
  limitProgress: 1,               // 只对相邻 1 张做变换，画面干净
  prev: { translate: ['-110%', 0, 0], rotate: [0, 0, -5], scale: 0.8 },   // 上一张：左移出画、逆时针 5°、缩到 0.8
  next: { translate: ['110%', 0, 0],  rotate: [0, 0, 5],  scale: 1.05 },  // 下一张：右移入画、顺时针 5°、放大 1.05
},
```

**验证**：点演示四的第 7 个按钮「creative 电影片」，轮播立刻变成选片墙——上一张斜靠在左侧变小，当前这张正中，下一张从右侧带着角度放大进场。若 1.05 觉得挤，把它调回 1 再看。

### 第 3 轮（答辩深挖：原理与参数含义）

**我的提示词：**

> creativeEffect 效果是什么原理？prev 和 next 里的 translate、rotate、scale 各控制什么？translate 的百分比是相对谁？

**AI 回答：**

**原理**：`effect: 'creative'` 会替换 Swiper 的内置切换动画，改由你在 `prev` / `next` 里定义相邻两张 slide 的"目标状态"。切换时 Swiper 给每次滑动计算一个进度值 progress（0→1），把 slide 的样式从「prev 描述的状态」平滑过渡到「next 描述的状态」——所以你写的是"两端的样子"，中间动画 Swiper 自动补。

**三项变换各自控制**：

| 项 | 控制什么 | 关键点 |
|---|---|---|
| `translate: [x, y, z]` | slide 的位移 | **x、y 的百分比相对 slide 自身的宽、高**（不是视口、不是容器）；z 用像素 |
| `rotate: [x, y, z]` | slide 的旋转 | 三个值是绕 X/Y/Z 轴的角度；做平面效果只用第 3 个（z 轴），正值顺时针 |
| `scale` | slide 的缩放 | 相对原尺寸的倍数，1 = 不缩放 |

**`limitProgress`** 决定对"相邻几张"应用变换：默认 1 → 只处理紧挨着的一张，其余隐藏。

**对照本页第 7 按钮的参数**：`prev: { translate: ['-110%', 0, 0], rotate: [0, 0, -5], scale: 0.8 }` 读作"上一张向左挪出自身宽度的 110%（完全出画还多留一成）、绕屏幕平面逆时针歪 5°、缩到原大的 0.8 倍"。

### 第 4 轮（动手实验：改一个数值看反应）

**我的提示词：**

> 改一个数值让卡片转 15 度试试

**AI 回答：**

只改 `rotate` 数组的**第 3 个值**（5 → 15，正负号表示方向），其余参数一律不动，粘到控制台重建实例：

```js
wySw4.destroy(true, true);
wySw4 = new Swiper('#wySw4', {
  effect: 'creative',
  creativeEffect: {
    limitProgress: 1,
    prev: { translate: ['-110%', 0, 0], rotate: [0, 0, -15], scale: 0.8 },  // 只改了这里：-5 → -15
    next: { translate: ['110%', 0, 0],  rotate: [0, 0, 15],  scale: 1.05 }, // 只改了这里：5 → 15
  },
  speed: 800,
  loop: true,
  keyboard: { enabled: true, onlyInViewport: true },
  autoplay: { delay: 3200, disableOnInteraction: false },
  pagination: { el: '#wyPag4', clickable: true },
});
```

**预期**：进出场的卡片从"轻微斜靠"变成"明显歪 15°"——印证 rotate 第 3 个值就是绕屏幕平面的旋转角。实验完刷新页面即恢复 5°。

好的，为「大国重器光影展」第六件作品生成首图。我使用的生图提示词：

### 第 2 轮（AI 初答踩坑：只给配置，粘进页面没反应）

**我的提示词：**

> Swiper 的 zoom 双击缩放怎么开启？我想给演示四的轮播加：双击图片放大、再双击还原，放大后还能拖动看细节。minRatio / maxRatio 各是什么意思？给完整配置。

**AI 回答（初答——有遗漏）：**

初始化时加 `zoom` 参数即可：

```js
zoom: {
  minRatio: 1,   // 还原后的最小倍数（1 = 原尺寸）
  maxRatio: 3,   // 双击放大的最大倍数（放大到 3 倍）
},
```

**minRatio / maxRatio 的意思**：zoom 的缩放被限制在这两个倍数之间——双击一次从 `minRatio` 放大到 `maxRatio`，再双击一次缩回去；放大后按住拖动可平移看细节，超出边界的拖动会被自动拉回。

**我按初答粘进页面后的验证结果：双击图片没有任何反应**——配置明明加了，zoom 却像没生效一样。

### 第 3 轮（排查修正：漏了 swiper-zoom-container）

**我的反馈（提示词）：**

> 还是没反应。zoom 配置加了，双击图片就是没有任何放大，控制台也没有报错，怎么回事？

**AI 回答（排查后修正）：**

抱歉，初答漏了一个关键点：**zoom 只对 `.swiper-zoom-container` 里的内容生效**。这个容器是 zoom 模块的"抓手"——Swiper 只把缩放 transform 应用在它内部。图片直接裸放在 slide 里时，zoom 找不到缩放目标，双击自然没反应（而且不会报错，这是它最隐蔽的地方）。slide 结构必须改成：

```html
<div class="swiper-slide">
  <div class="swiper-zoom-container">
    <img src="swiper-imgs/aidu_1.jpg" alt="爱达·魔都号">
  </div>
  <div class="wy-cap"><h3>爱达·魔都号</h3><p>…</p></div>
</div>
```

说明条（wy-cap）放在 zoom 容器外面，缩放时文字不跟着变形。

**修正后的验证**：演示四 6 张 slide 的 img 全部包进 `swiper-zoom-container` 后，双击立刻放大 3 倍、再双击还原、放大后可拖动平移——zoom 生效（截图见入口页「任务三」验证区）。
